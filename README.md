# BINGO - Console Bingo Game 2026

Javaで制作したコンソール型のBINGOゲームです。

基本的なBINGOゲームに加えて、3種類のゲームモードと
3×3、5×5、7×7のカードサイズを用意しています。

## ゲーム概要

プレイヤー名を入力してゲームを開始し、  
BINGOカードに表示された数字と抽選された数字が一致するとマスが開きます。

縦・横・斜めのいずれか1列がすべて開くとBINGOです。

カードサイズやゲームモードによって異なるルールで遊ぶことができます。

## 主な機能

- プレイヤー名の設定
- 3×3 / 5×5 / 7×7のカードサイズ選択
- 1～99の数字からBINGOカードをランダム生成
- 抽選数字の重複なしランダム生成
- FREEマス対応
- リーチ判定
- BINGO判定
- リーチ・BINGO状態の色分け表示
- BEST TURNの記録
- NORMALモードのスコア計算
- 3種類のゲームモード
- ゲームルールの確認
- コンソール上でのカラー表示

## ゲームモード

### NORMAL

通常のBINGOをプレイするモードです。

BINGOになるまでゲームを続け、
少ないターン数でのBINGOを目指します。

- BINGO達成までゲームを継続
- スコアを計算
- カードサイズごとにBEST TURNを記録
- BEST TURN更新時に`NEW`を表示

### ENDLESS

BINGOになってもゲームを終了せず、
同じカードで次のBINGOを目指し続けるモードです。

- BINGOするたびにカウント
- BINGO間のターン数を記録
- ゲーム全体のターン数を記録
- TOTAL BINGOを結果画面に表示
- ENDLESSモードのBEST TURNを記録
- スコア計算なし

### CHALLENGE

制限されたターン数以内にBINGOできるか挑戦するモードです。

| カードサイズ | 制限ターン |
| --- | ---: |
| 3×3 | 9ターン |
| 5×5 | 25ターン |
| 7×7 | 49ターン |

制限ターン以内にBINGOできれば`CLEAR`、
BINGOできなければ`FAILED`となります。

CHALLENGEモードではスコア計算を行わず、
NORMAL・ENDLESSとの差別化をしています。

## カードサイズ

### 3×3

9マスのコンパクトなBINGOカード。

短時間でBINGOを狙うことができます。

### 5×5

一般的なBINGOに近いサイズ。

標準的な難易度でプレイできます。

### 7×7

49マスの大きなBINGOカード。

BINGOまでに必要な数字が多く、難易度が高くなります。

## コンソール表示

ゲーム中はマスの状態に応じて色を変更しています。

| 状態 | 表示 |
| --- | --- |
| 通常の数字 | 通常表示 |
| 開いたマス | YELLOW |
| リーチ | ORANGE |
| BINGO | RED |
| タイトル | CYAN |
